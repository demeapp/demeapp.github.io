What the item proposed

The Cycling Network Plan and the associated Near Term Implementation Program (2019-2021), adopted by Council in July 2019 seeks to build on the existing network of cycling routes to connect gaps in the current network, grow the network into new parts of the city, and renew existing parts of the network to improve safety. This report is a second quarter update on cycling infrastructure projects that are proposed to be installed in 2021 and 2022 for which design and consultation have been completed. An updated Cycling Network Near Term Implementation Program and additional cycling infrastructure projects proposed for installation in 2022-2023 will be included in upcoming reports. This report also recommends the installation of sidewalks on local roads not otherwise delegated to the General Manager, Transportation Services as part of the Missing Link Sidewalk program.
